## 0. 一句话

做一个**安静、精准、有呼吸感**的本地训练工作台：首屏只有四个并列训练入口，点进去是清晰的步骤引导；毛玻璃只是材质，不是装饰堆砌；动画只服务于“浮现、聚焦、完成”。

---

## 1. 用户与场景

- 用户：中文 AI 创作者/研究者，能看懂“LoRA、rank、epoch”，但不一定懂 Python/CUDA。
- 场景：Windows 本机，GPU 可能是 4080/4090/5090；第一次打开时环境未配置；训练可能跑 10 分钟到几小时。
- 核心诉求：**别让我读文档；告诉我下一步点哪里；出问题告诉我为什么。**
- 次要用户：Agent（通过 MCP 操作）；UI 里只需要一个低调的“Agent 接入”入口，不占主流程。

## 2. 首屏（唯一重点）

### 2.1 结构
```
[左上] ModelSmith · 模匠          [右上] 环境 ✓  设置  Agent 接入

                 今天想训练什么？

  ┌────────────────┐  ┌────────────────┐
  │  决策模型训练    │  │  LLM 微调       │
  │  Laya · 快速判定 │  │  SFT / LoRA    │
  └────────────────┘  └────────────────┘
  ┌────────────────┐  ┌────────────────┐
  │  生图 LoRA      │  │  视频 LoRA      │
  │  FLUX / Z-Image │  │  Wan / H3      │
  └────────────────┘  └────────────────┘

              最近任务（最多 2 条，低调）
```

- 四张卡**等权并列**，2×2 网格；不要做成“主推一个、其余缩小”。
- 卡片只放：图标、标题、一行能力副标题、可选“已就绪/需配置”小状态。
- 不放：大段介绍、营销文案、统计数字、标签云、版本号。
- 首屏不使用侧边栏；设置/Agent 是右上角轻入口。
- 背景可以有极慢的呼吸光晕，但不能抢卡片；不要粒子雨/星空/鼠标拖尾。

### 2.2 图标与漂浮
- 每个入口一个**定制线性图标**（非 emoji、非通用圆角图标库直接套用）：
  - 决策模型：分叉路径 + 一个落点
  - LLM：层叠文本/对话气泡的抽象层
  - 生图：光圈/画框与颗粒
  - 视频：时间轴/连续帧
- 图标在卡片内**缓慢上下漂浮**（6–10px，6–9s，错峰），像悬浮在玻璃里；不要旋转、不要闪烁。
- hover：卡片抬升 2px + 光晕增强 + 图标漂浮暂停；不要弹跳、不要 3D 翻转。
- 首次加载：四张卡按 60–80ms 错峰浮现（fade + 8px rise + blur 1px → 0），整个过程 ≤700ms；只做一次。

## 3. 流程页（四条）

### 3.1 通用骨架
```
[← 返回]  生图 LoRA 训练                    [环境 ✓] [Agent]
────────────────────────────────────────────────────────────
 ① 选择架构    │                                    │ 本次预计
 ② 选择底模    │        当前步骤内容                 │ 显存  ~12 GB
 ③ 选择数据    │        （一次只做一件事）            │ 步数  1,200
 ④ 参数        │                                    │ 时长  ~35 min
 ⑤ 开始训练    │                                    │ 产物  ...
────────────────────────────────────────────────────────────
                         [上一步]        [下一步]
```

- 左侧步骤条：5 步以内；当前步高亮，已完成打勾；允许点回上一步，不允许跳过未完成步骤。
- 中间：**一屏只问一件事**；每个字段有一句“为什么/默认值”小字，不展开成长说明。
- 右侧：固定“本次预计”，随参数变化；数值用等宽数字；明确标“估算”。
- 底部：主按钮只有一个；上一步是次级按钮；危险操作（取消/覆盖）用文字按钮 + 确认。
- 高级参数：默认折叠，标题“高级参数（可选）”；展开后分组，不用二级弹窗。
- 顶部：返回、流程名、环境状态、Agent 接入；不放面包屑长链。

### 3.2 决策模型训练
步骤：
1. **选择底座**：English / Multilingual / Typed Decisions / 本地目录。每项显示参数量、上下文、用途一句话。
2. **选择数据**：拖入 JSONL 或文件夹；提供“用示例数据试跑”入口；显示格式提示（可折叠）。
3. **数据体检**：样本数、标签分布、超长、坏行、重复；问题用黄色行内提示，不弹模态。
4. **训练设置**：epochs、lr、batch、max_len、校准比例、选项交换；默认值旁标“推荐”。
5. **确认并开始**：显示预计显存/步数/时长 + 产物路径；开始后进入运行页。

运行页：阶段时间线（加载 → 数据 → 训练 → 校准 → 保存）、loss/acc 曲线、VRAM、日志尾随、取消。
完成页：准确率/AUC/校准温度、产物路径、“打开产物文件夹”“再训一次”。

### 3.3 LLM 微调
步骤：
1. **选择模型**：本地目录 / 模型 ID；显示参数量、上下文、显存档；不支持的架构直接禁用并说明。
2. **选择方法**：LoRA / QLoRA；全参放在“高级/高风险”里，默认不选。
3. **选择数据**：chat JSONL / instruction JSONL / 文本文件夹；模板自动识别，可改；给一条样例预览。
4. **数据体检**：轮数、token 长度、截断比例、空回复、角色格式。
5. **参数**：rank、alpha、lr、epochs、batch、grad accumulation、cutoff_len、seed；高级折叠。
6. **确认并开始**：预计显存/步数/时长。

运行页：loss/lr/VRAM/吞吐；完成页：验证 loss、固定 prompt 前后对比、adapter 路径。

### 3.4 生图 LoRA
步骤：
1. **选择架构**：FLUX.1 / FLUX.2 / Z-Image / Qwen-Image / SDXL / SD1.5；卡片式单选，显示“本机是否已有底模”。
2. **选择底模**：本地 safetensors / diffusers 目录；显示大小、哈希、架构匹配；不匹配直接红字阻止继续。
3. **选择数据**：拖入图片文件夹；显示缩略图墙；检测 `.txt` caption、缺 caption、重复、损坏。
4. **参数**：分辨率/bucket、rank、alpha、lr、steps、batch、save_every、sample prompts；默认配方一键用。
5. **确认并开始**：预计显存/步数/时长；提示“先 1 步试跑”可选。

运行页：loss、样本图（每 N 步）、VRAM、日志；完成页：采样对比、LoRA 路径、配置、数据清单哈希。

### 3.5 视频 LoRA
步骤：
1. **选择架构**：Wan2.2 / MiniMax-H3 / LTX-2.5；标注“需要多少显存”。
2. **选择底模**：本地文件/目录；架构/精度检查。
3. **选择数据**：视频片段 + caption；抽帧预览；显示时长/分辨率/帧率统计。
4. **参数**：帧数、分辨率、rank、lr、steps、batch、gradient checkpointing。
5. **确认并开始**：预计显存/步数/时长；显存不足时给“降分辨率/减帧数”的具体建议。

运行页：loss、采样帧、VRAM；完成页：采样视频/帧、LoRA 路径。

## 4. 视觉方向

### 4.1 气质
- 关键词：**深夜工作室、玻璃、精密仪器、安静**。
- 不要：赛博霓虹、紫蓝渐变堆满、发光边框、游戏 HUD、SaaS 卡片墙、巨大的营销标题。
- 毛玻璃只用于“浮层/卡片/侧栏”，不要全屏都糊；背景要有层次，但内容区必须清晰。

### 4.2 色彩（可微调，但需给理由）
```css
--bg-0: #080B10;       /* 页面最深 */
--bg-1: #0D1219;       /* 内容底 */
--glass: rgba(255,255,255,.055);
--glass-strong: rgba(255,255,255,.085);
--line: rgba(255,255,255,.12);
--text: #E8EEF7;
--text-dim: #93A1B5;
--text-faint: #5F6D80;

--laya: #5AD1A5;       /* 决策：薄荷 */
--llm: #7AA7FF;        /* LLM：雾蓝 */
--image: #F0B35A;      /* 生图：琥珀 */
--video: #C08CFF;      /* 视频：暮紫 */
--danger: #E06C75;
--warn: #E8B04B;
```
- 四个入口各用一个强调色，但**同屏最多两个强调色**：首屏四卡只让图标/细线带色，标题保持中性。
- 玻璃：`backdrop-filter: blur(18px) saturate(1.15)`；边框 1px 半透明；阴影极轻，不要大黑投影。
- 背景：2–3 个低饱和径向光晕，缓慢移动（≥20s），透明度 ≤0.12；内容区不叠纹理。

### 4.3 字体
- 中文：`"Source Han Sans SC", "Noto Sans SC", "Microsoft YaHei UI", sans-serif`。
- 拉丁/数字：`"Manrope", "Space Grotesk", "Segoe UI", sans-serif`；数字用 `font-variant-numeric: tabular-nums`。
- 字号：12 / 13 / 15 / 18 / 24 / 32；行高 1.45–1.65；标题字重 600，正文 400。
- 不要全大写 eyebrow、不要每个标题上加小标签、不要给单个词换色/斜体做“设计感”。

### 4.4 布局
- 首屏内容最大宽度 1080–1200px，垂直居中偏上；卡片间距 16–20px，圆角 20–24px。
- 流程页：左 200–220px 步骤条，中 560–680px 内容，右 260–300px 预估；总宽 ≤1200px。
- 小屏（<900px）：右栏折叠到内容底部；步骤条变顶部横向进度；卡片 1 列。
- 触控目标 ≥44px；键盘焦点环清晰（2px 强调色 + 2px 偏移）。

### 4.5 动效
- 只做三类：**入场编排、步骤切换、任务状态变化**。
- 入场：四卡错峰 60–80ms，fade + 8px rise + 轻微 blur；总时长 ≤700ms。
- 图标：6–9s 漂浮循环，错峰；hover 暂停。
- 步骤切换：内容 180–240ms 淡入 + 4px 位移；不要整页横滑。
- 进度：数字/曲线用 200ms 插值；不要无限旋转 spinner，改用阶段时间线。
- `prefers-reduced-motion: reduce`：关闭所有漂浮/入场/平滑滚动，只保留即时状态。
- 不允许：鼠标跟随光斑、粒子、持续抖动、闪烁、自动轮播。

### 4.6 文案
- 动词开头，句号省略；按钮说“开始训练”，不说“提交”。
- 空状态是邀请：“把图片文件夹拖到这里”，不是“暂无数据”。
- 错误说清“发生了什么 + 怎么修”，不道歉、不卖萌。
- 每个字段的小字只解释“为什么需要/默认值”，不超过 24 个汉字。

## 5. 关键组件
1. **入口卡**：图标 + 标题 + 一行副标题 + 状态点；玻璃、细边框、hover 光晕。
2. **步骤条**：数字/勾、标题、当前态；可点击回退。
3. **拖放区**：虚线边框 + 大图标 + 一句引导 + “选择文件夹”按钮；拖入后变文件摘要卡。
4. **数据体检卡**：通过/警告/错误三态；行内展开问题清单。
5. **参数行**：label + 控件 + 默认值徽标 + 一行小字；高级折叠。
6. **预估栏**：三行数字（显存/步数/时长）+ 产物路径；等宽数字。
7. **运行页**：阶段时间线、loss 曲线（SVG/canvas）、VRAM 条、日志尾随、取消按钮。
8. **完成页**：结果摘要 + 产物路径 + 打开文件夹 + 再训一次。
9. **Agent 接入抽屉**：显示 MCP 状态、复制配置、工具列表入口；默认关闭，不打扰主流程。

- 首屏除必要文案外无多余说明；四卡等权。

## 7. 不要做
- 不要做登录/注册/云同步/社区。
- 不要做顶部大导航、侧边栏、仪表盘统计。
- 不要做“AI 生成感”的默认套路：奶油底 + 衬线大标题 + 陶土色、黑底 + 荧光绿、SaaS 卡片墙、全大写小标签、每个按钮加 →。
- 不要把毛玻璃用在正文长文本上。
- 不要用动画掩盖加载；加载必须有阶段和真实状态。
