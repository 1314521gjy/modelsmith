# ModelSmith 设计规范（DESIGN-SPEC）

版本 2026-10-22 · 实现对象：`E:\视频\modelsmith\design\prototype\index.html`
需求唯一来源：`E:\视频\modelsmith\docs\UI-BRIEF-MINI.md`。设计法：`E:\视频\modelsmith\design\skills\frontend-design\SKILL.md`。
配套：实现建议见本目录 `ART-NOTES.md`。

**立意**：这是一张训练工作台，不是仪表盘。全站只留一个记忆点——一条 2px 的「进程缝」（seam）：流程页它是 4–6 步的进度线，运行页同一条线延展成阶段时间线。其余全部退到 1px 与 --dim。

## 1 色板 token

| token | 值 | 用途 |
| --- | --- | --- |
| --bg | `#080B10` | 页面底 |
| --bg2 | `#0D1219` | 面板内层、输入底 |
| --glass | `rgba(255,255,255,.055)` | 毛玻璃表面，`blur(18px)` |
| --line | `rgba(255,255,255,.12)` | 发丝分隔 |
| --line-strong | `rgba(255,255,255,.22)` | hover / 选中描边 |
| --text | `#E8EEF7` | 正文（目标 ≥4.5:1，未实测） |
| --dim | `#93A1B5` | 次要文字、静止图标、单位 |
| --laya | `#5AD1A5` | 决策线强调 |
| --llm | `#7AA7FF` | LLM 线强调 |
| --image | `#F0B35A` | 生图线强调 |
| --video | `#C08CFF` | 视频线强调 |
| --danger | `#E06C75` | 错误、取消 |
| --focus | `#A9C6FF` | 焦点环（本规范唯一新增色） |

- 强调色预算（硬约束）：首屏静止 = 0（图标用 --dim）；hover/focus 单卡 = 1；流程内 = 该线 1 + 状态色 1 = ≤2。四色永不常亮同屏。
- 两块径向光晕：--laya α.07、--video α.05 混入 --bg，只做明度层次，可见饱和度 <8%，不计入强调色预算。
- 状态点 = 颜色 + 文字（就绪 / 未检测 / 失败），不许只靠颜色。

## 2 字体与字阶

- 中文 `"Noto Sans SC","Microsoft YaHei UI",sans-serif`（后两者本机必有，断网不塌）；拉丁/数字 `"Manrope","Segoe UI",sans-serif`。
- 不用等宽字体做读数（生成页的默认味）；读数靠 `font-variant-numeric: tabular-nums` 对齐。
- 字阶（字号/行高/字重）：display 28/34/600（仅首屏标题）；h1 22/30/600（当前步骤）；h2 15/21/600（卡标题、分组）；body 14/22/400；small 12.5/18/400（--dim）；data 13/16/500 + tabular-nums。
- 中文 letter-spacing 0；拉丁标题 -0.01em；正文行长 ≤68 个全宽字符。
- 禁用：全大写小标签、每段上方的 eyebrow、标题里单词变色/斜体、按钮后缀 →、用「·」拼元信息、用破折号包装标签。

## 3 栅格与形状

- 容器 max 1120px 居中；页边距 24px（<640px 为 16px）；8pt 间距阶 8/16/24/32/48。
- 首屏：一块 24px 圆角面板，内部 2×2 等权单元，单元间只有 1px --line 十字分隔；单元不单独描边、不投影、不加渐变。四卡等权靠几何，不靠复制四张卡。
- 流程页：`200px | minmax(0,1fr) | 260px` 三栏，gap 32px；中栏内容列 max 560px；右栏 sticky top 88px。高级参数默认折叠。
- 圆角分档：面板 24 / 控件 12 / 小签 8。禁止全站一个半径。**次级圆角登记（2026-10-22 维护者 批准）**：次级面板 `.aside/.card-box` = 20px、次级小控件 `.xbtn` = 10px（见 `design\ART-NOTES.md` §3，token `--r-sub/--r-sub-ctrl`）。
- 层级：光晕 0 < 内容 1 < 底部操作条 20 < 抽屉 40 < skip link 60。
- 阴影只给抽屉与浮层（`0 8px 32px rgba(0,0,0,.45)`）；卡片一律不投影。

## 4 动效参数

| 场景 | 参数 |
| --- | --- |
| 四卡入场 | 每卡 delay i×70ms（60–80），opacity 0→1 + translateY 8px→0，260ms，`--ease: cubic-bezier(.22,.61,.36,1)`；末卡 470ms 收完（≤700ms）；每会话只播一次，返回首屏不重播 |
| 图标漂浮 | 7 / 8.5 / 7.5 / 9s 四档，translateY ±8px（6–10px），错峰 0/600/1200/1800ms；卡片 hover 或 focus-within 时 `animation-play-state: paused` |
| 卡片 hover | 抬升 2px + 底色 .055→.075 + 描边转 --line-strong，120ms |
| 步骤切换 | 内容区 200ms 淡入 + 4px 上移；旧内容直接移除；禁止整页横滑 |
| 光晕呼吸 | 24s / 32s，opacity .05↔.085，ease-in-out alternate；不位移、不缩放 |
| 进度与日志 | 进度条 width 240ms linear；日志即时追加，仅当用户已在底部时自动滚动 |
| 禁止 | 无限 spinner、骨架 shimmer、鼠标光斑、粒子、发光边框、渐变文字 |

### `prefers-reduced-motion: reduce`

1. 入场直接给终态；图标漂浮与光晕呼吸 `animation: none`。
2. 过渡压到 `0.001ms`，但状态差仍可见（焦点环、选中、错误态全部保留）。
3. 步骤切换瞬时；loss 曲线一次画完整，不做描线动画。
4. 假训练的定时器照常跑（读数更新与动画解耦）——「不动」不等于「停摆」。

## 5 组件状态

| 组件 | default | hover | focus-visible | disabled | error |
| --- | --- | --- | --- | --- | --- |
| 入口卡 | 透明底，图标 --dim | 图标转该线色，抬 2px | 2px --focus，offset 2 | 不适用（恒可点） | 不适用 |
| 主按钮 | 该线色 α.14 底 + α.45 描边，文字 --text | α.20 底 | 2px --focus，offset 2 | opacity .4 + `aria-disabled` + `cursor:not-allowed`，不可激活 | 不适用 |
| 次按钮（返回 / 上一步） | 透明 + 1px --line，--dim | 文字 --text，描边 --line-strong | 同左 | 第 1 步的「上一步」直接隐藏，不置灰 | 不适用 |
| 字段（select / input / 分段） | --bg2 底 + 1px --line，高 40 | --line-strong | 2px --focus + 描边 --focus | 底透明，文字 --dim，不可编辑 | 1px --danger + 字段下 12px 文案 + `aria-invalid` + `aria-describedby`；提交时焦点跳到第一个错字段 |
| 数据路径 / 拖放区 | 1px dashed --line，高 ≥96 | 实线 --line-strong + 底 α.04 | 同左环 | 不可投递 | 同字段 |
| 抽屉 / 开关 | 抽屉右侧 420px、24px 左圆角；开关 36×20，开=该线色 | 关→开 120ms | 环 2px | 整行 --dim + 说明 | 不适用 |
| 状态点 | 8px 圆点 + 文字 | 无 | 无（不可聚焦） | 无 | 圆点 --danger + 文案「失败」 |

- 所有可聚焦元素统一 `:focus-visible`，禁止裸 `outline: none`；指针点击不显环。

## 6 可访问性

- `lang="zh-CN"`；地标 header / main / nav（步骤条）/ aside（预估与抽屉）；每屏一个 h1。
- Tab 顺序 = 阅读顺序；首焦点为 skip link（激活跳 `#main`）或首个入口卡；无键盘陷阱。
- 抽屉：打开后焦点进第一项并在内部循环，Esc 关闭，关闭后焦点归还触发按钮。
- 步骤切换：焦点落到新步骤 h1（`tabindex="-1"`），`aria-live="polite"` 播报「第 N 步，共 M 步：<标题>」。
- 运行页状态行常驻 `aria-live="polite"`；日志区 `role="log"`。
- 图标纯装饰 `aria-hidden="true"`；状态点与错误都有文字，不靠颜色单通道。
- 触摸目标 ≥40×40px；200% 文本缩放不截断、不出横向滚动。
- 对比度目标：正文 ≥4.5:1，非文本（图标、细线、焦点环）≥3:1 —— **目标值，本次未用工具实测**，实测项在 QA H 组。

## 7 自评

**删掉的装饰（逐条点名）**

1. 删掉四张独立圆角卡片、各带阴影与渐变的 SaaS 卡片墙 → 一块面板 + 十字发丝线。
2. 删掉四卡图标常亮的四种品牌色 → 静止全 --dim，只在 hover/focus 上色（强化「一次只做一条线」）。
3. 删掉按钮后缀 →、全大写小标签、每段 eyebrow、单词变色标题。
4. 删掉 01/02/03 装饰编号（步骤条编号保留，因为步骤真是序列）。
5. 删掉等宽字体读数（mono 是生成页的标准套路），改用 tabular-nums。
6. 删掉「·」拼接元信息与「WORD — fragment」式标签。
7. 删掉发光边框、赛博霓虹、紫蓝渐变、渐变文字、鼠标光斑、粒子、骨架 shimmer、无限 spinner。
8. 删掉卡片 hover 放大与阴影加深（AI 默认味），只留 2px 抬升 + 描边提亮。
9. 删掉首屏说明段与功能列表：只留标题、四格、右上三项。
10. 删掉「大数字 + 小标签 + 渐变强调」的首屏 hero 套路：标题保持中性，数字只出现在预估与运行读数里，且是 tabular 真读数。

**为什么不是模板**

- 结构来自训练对象本身：步骤、预估、时间线、loss、VRAM 都是工作台的真实刻度，不是装饰；进程缝把「序列」这一信息重复用在两个页面，是内容驱动的复用而非造型。
- 同屏色数是从「四条产品线各自有颜色」反推出来的硬规则（静止 0 强调色），不是为了好看随手加的暗色滤镜。
- 唯一记忆点只花在进程缝上，其余全部安静（1px、--dim、无阴影、无发光）；这是 SKILL 的「把大胆花在一处，其余守纪律」。
